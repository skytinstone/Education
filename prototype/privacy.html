개인정보처리방침

업데이트: 2026년 11월 1일

Horcrux Technologies(이하 "당사")는 귀하의 개인정보를 소중히 여깁니다. 본 개인정보처리방침은 당사가 운영하는 Eureka 웹사이트(eurekai.cloud)와 시험 준비 AI 학습 서비스(이하 통칭하여 "서비스")를 이용할 때 당사가 귀하로부터 또는 귀하에 관하여 수집하는 개인정보를 어떻게 수집·이용·공개·보관하는지, 그리고 귀하가 어떤 권리를 가지는지 설명합니다. 본 방침은 「개인정보 보호법」 등 대한민국 관련 법령에 따라 작성되었습니다.

1. 당사가 수집하는 개인정보

귀하가 제공하는 개인정보

  • 계정 정보: 계정을 만들 때 귀하가 제공하는 이메일, 이름(닉네임), 비밀번호, 만 14세 이상 여부와 약관 동의 여부. 비밀번호는 복호화할 수 없는 방식으로 암호화하여 저장합니다.
  • 프로필 정보 (선택): 계정 설정에서 귀하가 원할 때 입력하는 생년월일, 학교, 전공, 주소, 프로필 사진. 프로필 사진은 저장할 때 새로 만들어 사진 속 위치·기기 정보(EXIF)를 남기지 않습니다.
  • 사용자 콘텐츠: 귀하가 서비스에 입력하거나 올리는 학습 요청, 대화 내용, 문제 풀이 답안, 서술형 풀이(타이핑한 글 또는 손글씨 이미지), 기출 파일(PDF·이미지), 학습 프로젝트 정보(과목, 목표, 시험일).
  • 커뮤니케이션 정보: 귀하가 당사에 문의하거나 피드백을 보낼 때 제공하는 이메일 주소와 메시지 내용.

서비스 이용 시 자동으로 수집되는 개인정보

  • 로그 데이터: 서비스에 접속할 때 브라우저가 자동으로 보내는 IP 주소, 브라우저 종류와 설정, 요청 일시, 오류 기록.
  • 사용 데이터: 귀하가 푼 문제와 정답 여부, 오답노트, 저장한 문제, 암기 카드 학습 상태, 학습한 날짜 등 서비스 이용 기록.
  • 브라우저 저장소와 쿠키: 로그인 상태 유지를 위해 브라우저 저장소(localStorage)에 로그인 토큰을 저장하고, 간편 로그인 과정의 위조 방지를 위해 10분짜리 일회성 쿠키를 사용합니다. 광고나 행태 분석 목적의 쿠키는 사용하지 않습니다.

다른 출처로부터 받는 개인정보

  • 간편 로그인: 귀하가 Google 또는 카카오로 로그인하면, 귀하의 동의를 받아 해당 업체로부터 계정 식별자, 이메일, 이름(닉네임)을 받습니다.

2. 개인정보 이용 방법

당사는 다음과 같은 목적으로 개인정보를 이용합니다.

  • 서비스 제공, 운영 및 유지 — 계정 생성과 로그인, 본인 확인, 문제 생성·채점, 오답노트, 약점 분석, 개념 정리와 암기 카드 제공
  • 귀하가 올린 기출 자료의 구조를 분석해 귀하만을 위한 새 문제를 만드는 것
  • 서비스 개선과 오류 확인, 새로운 기능 개발
  • 귀하와의 커뮤니케이션 — 문의 응답, 서비스 변경 안내, (귀하가 동의한 경우) 학습 알림과 소식 전달
  • 사기·부정 이용·보안 사고의 방지와 대응, 서비스와 이용자의 보호
  • 법적 의무의 이행과 당사 권리의 보호

당사는 귀하의 사용자 콘텐츠로 자체 AI 모델을 학습시키지 않습니다. 서비스의 AI 기능은 외부 AI 제공업체의 API 를 통해 제공되며, 해당 업체의 API 정책상 API 로 전달된 데이터는 기본적으로 모델 학습에 사용되지 않습니다. 당사는 개인을 식별할 수 없도록 집계하거나 비식별화한 정보를 서비스 품질 분석에 이용할 수 있으며, 이를 다시 식별하려고 시도하지 않습니다.

4. 보유 및 파기

  • 계정 정보와 사용자 콘텐츠: 회원 탈퇴 시까지 보유하며, 탈퇴하면 지체 없이 파기합니다.
  • 장애 복구용 백업: 백업 시점으로부터 최대 90일 보관 후 자동 삭제됩니다. 탈퇴 후에도 이 기간 동안 백업본에 남아 있을 수 있으나 복구 목적 외에는 사용하지 않습니다.
  • 로그 데이터: 최대 90일 보관합니다.
  • AI 제공업체: OpenAI 는 부정 이용 감시를 위해 API 로 받은 데이터를 최대 30일 보관한 뒤 삭제합니다 (OpenAI API 데이터 정책).
  • 관련 법령에 따라 보존 의무가 있는 경우 해당 기간 동안 보관합니다.

보유 기간이 끝나거나 처리 목적이 달성된 개인정보는 지체 없이 파기합니다. 전자 파일은 복구할 수 없는 방법으로 삭제하고, 백업본은 보관 기간이 지나면 자동 삭제됩니다.

5. 귀하의 권리

귀하는 관련 법령에 따라 다음과 같은 권리를 가집니다.

  • 자신의 개인정보에 대한 열람, 정정, 삭제, 처리 정지 요청
  • 개인정보 처리에 대한 동의 철회 (마케팅 수신 동의 포함)
  • 회원 탈퇴 — 계정 설정 → 회원 탈퇴에서 바로 할 수 있으며, 탈퇴하면 학습 기록과 올린 파일이 즉시 삭제됩니다.

프로필 정보는 계정 설정에서 직접 고칠 수 있습니다. 그 밖의 요청은 12번의 연락처로 보내 주시면 10일 이내에 처리하고 결과를 알려 드립니다. 법정대리인이나 위임을 받은 사람을 통해서도 권리를 행사할 수 있으며, 이 경우 위임 사실을 확인할 수 있는 서류를 요청할 수 있습니다.

6. 아동

서비스는 만 14세 이상을 대상으로 하며, 당사는 만 14세 미만 아동의 개인정보를 알면서 수집하지 않습니다. 만 14세 미만 아동이 개인정보를 제공한 사실을 알게 되면 해당 정보를 삭제합니다. 그런 사실을 알고 계시다면 12번의 연락처로 알려 주세요.

7. 다른 웹사이트로의 링크

서비스에는 Google, 카카오 등 당사가 운영하지 않는 웹사이트나 서비스로의 링크가 있을 수 있습니다. 해당 웹사이트에서 귀하가 제공하는 정보는 그 웹사이트의 개인정보처리방침과 이용약관을 따르며, 본 방침은 적용되지 않습니다.

계정 설정의 주소 검색은 카카오 우편번호 서비스를 이용하며, 검색할 때 입력한 검색어는 귀하의 브라우저에서 카카오로 직접 전송됩니다. 당사는 귀하가 고른 주소만 저장합니다.

학교 검색은 교육부 나이스(NEIS) 교육정보 개방 포털의 공개 학교 정보를 이용하며, 당사 서버가 귀하가 입력한 학교 이름 검색어만 전달합니다.

8. 보안

당사는 개인정보를 분실, 오용, 무단 접근, 공개, 변경, 파기로부터 보호하기 위해 합리적인 기술적·관리적 조치를 취합니다.

  • 비밀번호의 일방향 암호화(Argon2)와 모든 통신의 HTTPS 암호화
  • 데이터베이스의 외부 직접 접속 차단, 서버 접근을 인증된 관리자로 제한
  • 이용자는 자신의 데이터만 볼 수 있도록 하는 접근 통제
  • 백업은 외부에 공개되지 않는 저장소에 보관

다만 인터넷을 통한 전송이나 전자 저장 방식은 완벽하게 안전할 수 없으므로, 귀하도 비밀번호를 안전하게 관리해 주시기 바랍니다.
